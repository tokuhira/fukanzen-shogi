## 1. `count_attackers`（movegen）

```rust
/// side の駒が sq に利いている枚数を数える。呼び出し側は sq を空けた盤を渡す（(b)・§3）。
pub fn count_attackers(pos: &Position, sq: Square, side: Side) -> usize {
    pos.board
        .iter() // (Square, Piece) を返す既存イテレータ。無ければ全マス走査で代替
        .filter(|(from, piece)| piece.side == side && piece_attacks(pos, *from, *piece).contains(&sq))
        .count()
}
```

- `pos.board` の駒イテレート方法は現物に合わせる（`opponent_attacks`（`:127-135`）が同じ走査をしているので、その形を踏襲）。
- **(b) 串刺し方式**: 資格判定は §3 で「**S を空けた盤**」で呼ぶ。S を空けると、S の裏に控えた**攻め側の走り駒（後詰め）も利きが透けて**数えられる（守り側は取られた駒が消えて元々透ける）。空マス S は `slide_attacks` が push して通過するので、後詰めの飛・角・香がそのまま計上される。値と多段順序は見ない（枚数のみ）。

## 3. `resolve_independent` の没収分岐（§4.1 取得の解決差し替え）

`:280`（両駒を `next` に配置）の直後、`:282` の `move_number += 1` の**前**に挿入。**両側 d/a を先に数えてから適用**する。

```rust
// v0.7: 支え付き取得の利き数没収。玉が死んだターンは対象外（ゲーム終了・5.2 の領分）。
let mut sente_forfeit: Option<PieceKind> = None;
let mut gote_forfeit: Option<PieceKind> = None;
if !sente_king_died && !gote_king_died {
    // (b) 串刺し方式: 取り合いマスを空けた盤で両側を数える（S の裏の後詰めを攻守とも計上）。
    // 両側を先に評価してから適用（順序依存回避）。
    let s_forfeit = if sente_cap.is_some() && sente_piece.kind != PieceKind::King {
        let mut t = next.clone();
        t.board.set(ts, None); // 取りに行った駒を透かす
        count_attackers(&t, ts, Side::Gote) > count_attackers(&t, ts, Side::Sente)
    } else {
        false
    };
    let g_forfeit = if gote_cap.is_some() && gote_piece.kind != PieceKind::King {
        let mut t = next.clone();
        t.board.set(tg, None);
        count_attackers(&t, tg, Side::Sente) > count_attackers(&t, tg, Side::Gote)
    } else {
        false
    };
    if s_forfeit {
        next.board.set(ts, None);
        next.hand_gote.add(sente_piece.kind.unpromoted());
        sente_forfeit = Some(sente_piece.kind);
    }
    if g_forfeit {
        next.board.set(tg, None);
        next.hand_sente.add(gote_piece.kind.unpromoted());
        gote_forfeit = Some(gote_piece.kind);
    }
}
```

- `sente_piece`/`gote_piece` は `:270`/`:276` で既に束縛済み（成り反映後の kind を持つ）。没収時 `.unpromoted()` で基本種を駒台へ（`:117` 等と同じ流儀）。
- **d = 取られた側の利き数、a = 取った側の利き数**（ともに S を空けた盤 `t` で数える＝(b)）: 先手の取得（S=ts、取られたのは後手駒）→ d=`count(t,ts,Gote)`, a=`count(t,ts,Sente)`。後手の取得（S=tg）は対称。S を空けると攻め側の後詰めが透けて数えられる（守りは元々透ける）。
- 変数名は現物に合わせる（`ts`/`tg` は `:210-211` で束縛済み）。
- event 構築（`:288` の `(false, false)` 枝）に `sente_forfeit`/`gote_forfeit` を渡す。他の枝（king died）は Normal でないので触らない。

## 5. テスト（`resolve.rs` の `#[cfg(test)]`・table）

`make_pos` を使い、v0.7 没収の要点を固定（d/a は移動完了時点で数える）:

- **浮き駒（d=0）は没収なし**: 既存 `capture_value_independent`（`:326`）が該当（後手飛に支えなし）。**先手歩が 5e を占める**まま——版上げ後も緑であることを確認（回帰）。
- **支え一枚・後ろ盾なし（d=1,a=0）は没収**: 後手飛 5e を後手金 4f 等で支え、先手歩 5f→5e。結果: 先手駒台に飛1、**先手歩は先手盤上から消え後手駒台に歩1**、5e は空。
- **利き足しで没収されない（a≧d）**: 上に加えて先手が別の駒で 5e を支え（a=1）。結果: 通常取得——先手歩が 5e に残り、駒台は飛1のみ、没収なし。
- **玉が取った側は没収しない（判断1）**: 先手玉が支え付き（移動後）後手駒を取る配置で d>a を作り、**玉は没収されない**（盤上に残る・駒台に載らない）。
- **同ターン双方の支え付き取得**: 先後が同時に支え付き駒を取り、双方 d>a → **双方没収**（両側を先に数えてから適用する順序独立を確認）。
- **後詰めが攻守対称に効く（(b)）**: S の裏に守りの後手走り駒と攻めの先手走り駒を一枚ずつ対称に置く。S を空けて数えるので d=a → a≧d → **没収されない**（攻めの後詰めが正当に効く）。
- **守り側だけ後詰めが多いと没収**: 上から攻めの後詰めを外す（または守りを一枚増やす）と d>a → 没収成立。攻めの後詰めが透けて数えられること（(b)）を、この対比で固定。
- 既存の相討ち・戦国無双・玉の死テストは**無傷**（Case 1/2 無変更・Normal 拡張は `..`）。

## 不変の原則

- **取得だけ触る**: `resolve_independent` にのみ没収。`resolve_clash`/`resolve_king_wins` は無変更。
- **移動完了時点で数え、合法性は着手開始時点**: 二時点を混ぜない（§3 無変更）。
- **両側を先に数えてから適用**: 同時性を保つ（順序依存を出さない）。
- **玉は没収しない**: 非玉ガード。
- **(b) 串刺しで攻守対称**: 取り合いマスを空けて数え、S の裏の後詰めを攻守とも計上する。値・多段順序は見ない（枚数のみ）。
- **版は engine が名乗り、他は読むだけ**: `RULE_VERSION` を上げれば archive/negotiate が追随。X-b ゆえディスパッチは作らず、v0.6 は仕様と git に残す。
- **表示は殻・後段**: engine 核は盤面を正しくするまで。没収の可視化は Step 2、deploy は別段。
